\# AI Content Inspector: Human vs. AI Text Analysis Platform



Full-stack web application that predicts whether a text was written by a \*\*human\*\* or generated by an \*\*AI model\*\*, with a confidence score. Built for the WEX 428 Machine Learning course at OSTIM Technical University.



\*\*Live demo:\*\* https://ai-content-inspector.onrender.com

(free hosting: the first load can take about 50 seconds while the server wakes up, and accounts and history may reset when it restarts)



\## Features

\- Register, login, and a profile page (photo, personal info, change password, delete account)

\- Analyze pasted text or an uploaded `.txt` file

\- Result page with the prediction (Human / AI) and the confidence score

\- History page: search, filter and delete previous analyses

\- Dashboard with charts of your analyses

\- Input validation, JWT authentication, responsive design



\## Tech stack

| Part | Technology |

|---|---|

| Frontend | React (Vite), React Router, Chart.js |

| Backend | FastAPI (Python), REST API |

| Database | SQLite with SQLAlchemy |

| Machine learning | scikit-learn: TF-IDF + Logistic Regression (trained by us, no external LLM API) |

| Deployment | Docker on Render |



\## Machine learning model

\- Dataset: \*Human vs. LLM Text Corpus\* (Kaggle)

\- Model: TF-IDF features + Logistic Regression

\- Test accuracy: about 88% (human recall 0.83, AI recall 0.92)

\- Training script: `ml/train\_baseline.py`, saved model: `ml/baseline\_model.joblib`



\### Limitations

\- The model was trained on English text only. Other languages are often wrongly labelled as AI.

\- Short or very simple texts are often labelled as AI.

\- A prediction is a statistical estimate, not proof of authorship.



\## Run locally

Requirements: Python 3.11 and Node.js.



\*\*Backend\*\* (port 8000):

```

python -m venv .venv

.venv\\Scripts\\activate

pip install -r requirements.txt

uvicorn backend.main:app --reload

```

API docs: http://127.0.0.1:8000/docs



\*\*Frontend\*\* (port 5173), in a second terminal:

```

cd frontend

npm install

npm run dev

```

Open http://localhost:5173



\## Run with Docker

```

docker build -t ai-content-inspector .

docker run -p 10000:10000 -e PORT=10000 -e SECRET\_KEY=change-me ai-content-inspector

```

Open http://localhost:10000
